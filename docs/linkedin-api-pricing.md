# LinkedIn API: Automated Posting & Pricing (2026)

## Automated posting support

LinkedIn supports automated posting via the UGC Posts API (`POST https://api.linkedin.com/v2/ugcPosts`, header `X-Restli-Protocol-Version: 2.0.0`). Three ways to automate:

- **Native scheduler** — free, schedule up to 3 months ahead, but manual and one post at a time.
- **Scheduling tool** — content calendar, approvals, multi-network publishing.
- **Direct API integration** — post programmatically to your own account.

## Pricing structure

LinkedIn doesn't publish per-month pricing. Based on 2026 data:

| Tier | Cost |
|---|---|
| Consumer tier (sign-in + posting to own feed) | Free |
| Marketing API (Company Profile access, approved partners) | ~$699+/month |
| Sales Navigator API (SNAP) | $99+/seat/month — **not accepting new partners** |
| Enterprise agreements | $50,000–$300,000+/year |

## Access & gating

The free consumer tier covers sign-in and posting to your own feed. Anything beyond that — company pages, ads, moderation — lives behind the Marketing Developer Platform and is partner-gated with no published price. The real cost is a **3–6 month approval/review cycle**, not a monthly fee. Sales Navigator API access is currently closed to new partners with no reopening timeline.

**Bottom line:** the barrier for a tool like Postwise isn't price — it's getting approved as a LinkedIn Marketing Developer Platform partner to post beyond a single user's own feed.
